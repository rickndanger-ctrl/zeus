# Zeus for macOS

A floating lightning orb for desktop dictation.

**[Download Zeus for macOS](https://github.com/rickndanger-ctrl/zeus/releases/download/v0.1.0/Zeus-0.1.0-macOS.dmg)** · [Release notes](https://github.com/rickndanger-ctrl/zeus/releases/tag/v0.1.0)

Developer ID signed and notarized by Apple.

## Install

1. Download the DMG from Releases.
2. Drag Zeus to Applications and open it.
3. Allow microphone and speech recognition access, then enable Zeus in macOS Accessibility settings.

Requires macOS 14 or later. The download supports Apple silicon and Intel; physical use has been tested on Apple silicon.

## Use

Click a message box, then click the orb and talk. Click again to place your words. Send the message yourself. In Settings, enable stay-on and two-second silence placement to dictate continuously. Drag the orb anywhere; it remembers its position. Right-click to clear the current dictation or stop listening. Optional local wake-phrase listening is available.

This desktop preview does not promise support for every text editor. Phone integration and automatic message submission are not included in this release's supported workflow.

## Privacy

Desktop speech recognition uses the on-device engine. Microphone and Accessibility access are required to recognize speech and place text. Unsent recovery text may be retained locally. Do not include private dictation in public bug reports.
